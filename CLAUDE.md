# Para agentes

- Responde y escribe en español (código, comentarios, PR), breve.
- Trabajo en curso: el sistema de salas en la rama `salas`. Antes de nada, lee
  [`docs/salas/README.md`](docs/salas/README.md) (estado, forma de trabajar, mapa del código) y,
  para la prioridad actual, [`docs/salas/obras-rework.md`](docs/salas/obras-rework.md).
- Antes de subir: `npm run lint && npm run format:check && npm run typecheck && npm test && npm run build`.
